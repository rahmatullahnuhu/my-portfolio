/ About

Clean on the surface. Careful underneath.

I’m Nuhu, a developer in Dhaka. I’ve built more than 100 websites for clients, and I currently build them at Softvence Delta. I’m comfortable in the visual builders and just as comfortable writing code when a design needs more than a builder can give.

My clients come from real estate, e-commerce, healthcare, insurance, food and tourism. The brief changes, the standard doesn’t: quick on every screen and easy to hand over.

/ Custom code

I write the code when a builder runs out of room.

Some designs need animation, structure or logic that no template allows. I build those by hand in HTML, CSS, JavaScript, React and Next.js, and I leave the code clean enough for the next developer.

/ Platforms

Most sites need the right platform, not a custom build.

WordPress, Squarespace, Wix and Framer each fit a different team and budget. I pick the one that suits you, then shape it until it no longer looks like a template.

/ Launch
